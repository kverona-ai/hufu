## Hufu 1.0.0, the first stable release

Hufu is a local multi-agent dispatch layer with a pluggable commander: any coding agent can plan and
review, and any other agent can be dispatched to do the work, with one task spec, one set of
commands and one result format. 1.0 drives Codex, Claude Code, Antigravity, Cursor, Kimi Code, pi
(and through it OpenRouter, DeepSeek, Z.ai and other model APIs) and any agent that speaks the Agent
Client Protocol, on Linux, macOS and Windows.

### New in 1.0

- **Checked against every agent's latest release.** Each adapter was compared with its agent's
  official documentation and changelog on 2026-11-20; what changed and the evidence for it are in
  [the agent landscape](https://github.com/kverona-ai/hufu/blob/main/doc/research/agent-landscape.md).
- **`xhigh` on the effort scale**, between `high` and `max`, mapped for every agent that has it.
- **`hufu models <profile>` and the `hufu_models` MCP tool** ask the agent itself which models and
  effort levels it offers: `codex debug models`, `agy models`, `cursor-agent models`,
  `pi --list-models`, Kimi Code's `config.toml`, or an ACP session.
- **Cursor runs as `cursor-agent`**, and an `agent` command that belongs to another CLI is no longer
  mistaken for it.
- **Permission tiers no longer depend on the agent's own settings**: an `agy acp` preset, explicit
  modes for Antigravity and Claude Code, and Cursor's unrestricted approval mode detected.
- **Kimi Code jobs can be resumed**, and more pi providers are recognised.

### Install

Ask the coding agent you already use:

```text
Install and configure Hufu on this machine. Follow the guide at
https://raw.githubusercontent.com/kverona-ai/hufu/main/doc/guide/agent-install.md
and tell me what you changed and what is left for me to do.
```

Or by hand: `curl -fsSL https://raw.githubusercontent.com/kverona-ai/hufu/main/src/install/install.sh | sh -s -- --up`
(macOS and Linux), or the PowerShell line in the
[README](https://github.com/kverona-ai/hufu#install-and-start). An installed Hufu moves to this
release with `hufu update`.

### Issues welcome

This is the first stable release, and your reports make the next one better. Please
[open an issue](https://github.com/kverona-ai/hufu/issues/new/choose) for a bug, an agent or model
that behaves differently from what Hufu expects, a question or an idea. Chinese or English are both
fine.

## 虎符 1.0.0，第一个正式版

虎符是一个本地的多 Agent 调度层，指挥者可以替换：任何编程 Agent 都可以负责规划和审查，再把活派给
其他 Agent 去做，任务描述、命令和结果格式都只有一套。1.0 支持 Codex、Claude Code、Antigravity、
Cursor、Kimi Code、pi（以及通过它接入的 OpenRouter、DeepSeek、Z.ai 等模型 API）和任何支持 Agent
Client Protocol 的 Agent，可在 Linux、macOS 和 Windows 上运行。

### 1.0 的新内容

- **按各 Agent 的最新版本逐一核对。** 2026-11-20 对照各家官方文档和更新日志检查了每个适配器，
  变化和依据记在[调研文档](https://github.com/kverona-ai/hufu/blob/main/doc/research/agent-landscape.md)里。
- **effort 档位新增 `xhigh`**，介于 `high` 和 `max` 之间，已为支持它的 Agent 做好映射。
- **`hufu models <profile>` 和 MCP 工具 `hufu_models`** 直接向 Agent 询问它提供哪些模型和 effort 档位。
- **Cursor 以 `cursor-agent` 运行**，其他 CLI 安装的 `agent` 命令不会再被误认成 Cursor。
- **权限档位不再依赖 Agent 自己的设置**：新增 `agy acp` 预设，Antigravity 和 Claude Code 显式指定模式，
  能识别 Cursor 的无限制审批模式。
- **Kimi Code 的任务可以续跑**，pi 新增多个模型提供方。

### 安装

对你正在用的编程 Agent 说"按 https://raw.githubusercontent.com/kverona-ai/hufu/main/doc/guide/agent-install.md
的步骤在这台机器上安装并配置虎符"即可，手动安装见 [中文 README](https://github.com/kverona-ai/hufu/blob/main/README.zh-CN.md)。
已安装的用 `hufu update` 升级。
